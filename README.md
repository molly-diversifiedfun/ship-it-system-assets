# Ship It System — Public Assets

Brand assets for the Ship It System product line. Public mirror of select graphics from the (private) `ship-it-system` repo. These need a public host for Notion cover images, Medium post headers, LinkedIn images, and embeds on theshipitsystem.com.

## What's here

- `covers/` — page-cover illustrations in Molly's locked Unstuck soft-pink-sketch style (xkcd hand-drawn + soft pink/mauve watercolor + 16:9 wide + hand-lettered text)

## Conventions

- All covers are 16:9 horizontal, ~700-1500 KB PNG
- Generated via `nano-banana` (Gemini Imagen) — style locked in `unstuck-image-style.md` in the parent repo
- Refresh quarterly alongside the vendor research

## Canonical hosting URL pattern

```
https://raw.githubusercontent.com/molly-diversifiedfun/ship-it-system-assets/main/covers/<filename>.png
```

Use this URL pattern for Notion page covers, Medium post header images, and anywhere else needing a public, stable, brand-consistent image URL.

## Not here

- The Ship It System product IP (modules, T-templates, extensions, AI Build Partner skill) — stays in the private `ship-it-system` repo
- Buyer-facing content drafts — stays private until published
